Test plan

Every test still to run, grouped by part of the JACON. Each one says how to wire it, who does what, and what comes out. Mark them validated as they get done.

Before any of it: read the maximum input power printed on the Signal Hound SM200B and never exceed it. Put a fixed attenuator in front of it whenever an amplifier is in the path. Use a DC block if the part under test can put DC on its output. Never cable the Furuno radar to anything: it is 2.2 kW peak. Radar tests are over the air only.

Open question, blocks the RX tests: what makes the 9.3 to 9.5 GHz test signal? Three choices. One: the ADF5355 set to 9.4 GHz, if there is a second one or we borrow the LO for a while. Two: Pluto at 1.0 to 1.2 GHz into the TX mixer with the 8.3 GHz LO, which is the TX chain doing its real job. Three: the Furuno radar over the air. I recommend two, because it sweeps and I can control it.

RX chain

Antenna, limiter, LNA, mixer, IF amp, splitter. Test each part alone first, then stack them one at a time.

RX-0. The source and the cables

do this first

Wire: 9.4 GHz source → cable → SM200B. Then swap in each cable you plan to use, one at a time.

You: connect, tell me which cable is in.

I: sweep 9.3 to 9.5 GHz, read level and frequency.

You get: source power and frequency across the band, its spurs, and the loss of every cable at 9.4 GHz. Everything later is subtracted from this.

RX-1. Horn antennas

8.2–12.4 GHz horns

Wire: source → horn A, facing horn B → SM200B. Measure the gap. At least 1 m, more is better.

You: set the gap, then turn one horn 90° when I ask.

I: sweep and read received power both ways round.

You get: gain of the horns in dBi across the band (drawing says 10 to 15), and how much a crossed polarization costs.

\[ G_\text{dBi} = \tfrac{1}{2}\left( P_r - P_t + 20\log_{10}\frac{4\pi d f}{c} \right) \]

RX-2. Power limiter

whichever limiter is picked

Wire: source → limiter → SM200B.

You: add or remove attenuators to step the input power.

I: read output at each step.

You get: its small-signal loss at 9.3 to 9.5 GHz, and the level where it starts clamping. Pass if the output never tops +15 dBm, the LNA’s limit. We may not have enough power to reach clamping; I will say so if not.

RX-3. LNA

ZX60-5123LN+, 12 V

Wire: source → 30 dB attenuator → LNA → 20 dB attenuator → SM200B. Then again with a 50 Ω load on the LNA input instead of the source.

You: power the LNA, read me the current, swap attenuators for the power sweep.

I: sweep frequency, then step input power, then read the noise floor with the input terminated.

You get: gain across the band (expect +22 dB), where it compresses (expect +17 dBm out), and a rough noise figure (expect 1.4 dB, mine will be good to about 1 dB).

\[ NF \approx N_\text{out}\,[\text{dBm/Hz}] + 174 - G \]

RX-4. LO chain

ADF5355 → ZX60-14012L-S+ → ZX10-2-1252-S+

Wire: PLL → SM200B. Then add the buffer amp. Then the splitter, reading each output with the other terminated.

You: set the PLL to 8.3 GHz, add one part at a time.

I: read frequency, power, close-in spurs at each stage.

You get: the real LO frequency, and the power arriving at each mixer. The mixers want +10 dBm. If it is short, we know before blaming the mixer.

RX-5. RX mixer

ZX05-14LH-S+

Wire: source at −20 dBm → RF port. LO chain → LO port. IF port → SM200B.

You: connect, confirm the LO level from RX-4.

I: step the RF from 9.3 to 9.5 GHz and read the IF at 1.0 to 1.2 GHz. Then look for the 8.3 GHz LO leaking out of the IF port.

You get: conversion loss across the band (expect 6.7 dB), LO leakage at the IF port, and how flat the 200 MHz band comes out.

RX-6. IF amp

ZX60-P162LN+ (and the other two)

Wire: Pluto → 30 dB attenuator → amp → 20 dB attenuator → SSA3021X or SM200B.

You: power the amp, swap attenuators.

I: step the Pluto across 1.0 to 1.2 GHz and up in level, read the output.

You get: gain across the band (expect 22.5 dB) and the most power it can put out. That last number matters: the phase-detector mixer dies at +17 dBm.

RX-7. IF splitter

ZFRSC-42-S+

Wire: Pluto → splitter. One output → analyzer, the other → 50 Ω load. Then swap.

You: swap the outputs.

I: step 1.0 to 1.2 GHz, read both.

You get: loss on each side (expect 6.0 to 6.5 dB) and how well they match.

RX-8. The whole RX chain, cabled

limiter → LNA → mixer → IF amp → splitter

Wire: source → attenuators → limiter → LNA → mixer → IF amp → splitter → SM200B. Add one part per run.

You: add the next part, set the attenuators I ask for.

I: sweep frequency and input level from −50 to −10 dBm.

You get: total gain against the sum of the parts, the input level where the chain starts to compress, and the IF level at each splitter output for a weak and a strong radar.

RX-9. Over the air, then the real radar

horn in front, radar far away

Wire: horn → limiter → attenuator → SM200B first, with no LNA. Only then the full chain.

You: place the horn, run the radar, keep people out of the beam.

I: capture pulses with the SM200B.

You get: the radar’s real frequency, pulse width, repetition rate and received power at that distance. Then the same pulse as it leaves the splitter at 1.0 to 1.2 GHz.

Phase detector

Done once already, in the wrong band and at one power. These redo it properly.

PD-1. Calibration in the real band

Wire: Pluto → splitter → two cables → mixer → scope CH2. Tee to the analyzer.

I: step 1.0 to 1.2 GHz in 1 MHz steps, read voltage and true frequency.

You get: mV against MHz in the band that matters, and whether it goes one way across all 200 MHz.

PD-2. Power sensitivity

Wire: same as PD-1.

I: repeat the sweep at five power levels.

You get: how many MHz of error each dB of power change causes. This sets how good the limiting amp must be.

PD-3. Delay length

Wire: same, swapping the extra cable: none, 1.5 in, 4.5 in, longer.

You: swap the cable.

You get: which length gives a one-way curve over 1.0 to 1.2 GHz with the steepest slope. Also tests my reflection guess.

PD-4. With the limiting amp

Wire: Pluto → attenuators → limiting amp → splitter → mixer.

You get: the same curve for inputs from −37 to +3 dBm, if the limiter works. Check the amp’s output is under +23.5 dBm first.

PD-5. Speed with a real pulse

Wire: Pluto pulsed, 50 ns to 1.2 µs → chain → scope.

You get: how long after the pulse starts the voltage is good enough to sample. The racon has 0.7 µs in total.

Envelope detector and comparator

ENV-1. Detector curve

ADL5511

Wire: Pluto → attenuators → detector → scope.

I: step the level, read the output voltage.

You get: volts out against dBm in at 1.0 to 1.2 GHz.

ENV-2. Pulse response

Wire: Pluto pulsed → detector → scope.

You get: rise and fall time of the detector. It must be well under 50 ns to see the shortest radar pulse.

ENV-3. Comparator and DAC

ADCMP600 + nanoDAC

Wire: detector → comparator, DAC sets the threshold, scope on both.

You get: the delay from pulse edge to comparator edge, and the weakest pulse that still trips it at each DAC setting.

TX chain

TX-1. VCO in the real band

Wire: tuning source that reaches 8 V → VCO → attenuator → analyzer.

You: build the op-amp stage, or drive it from a supply by hand.

You get: the tuning table from 4.8 to 7.8 V, in its final wiring.

TX-2. Sample and hold

ADG1211 + 100 pF + ADA4622-1

Wire: Syscomp step → sample and hold → scope.

You get: how fast it grabs, and how much it droops while holding. The VCO needs it steady to ±22 mV.

TX-3. Keying switch

ADG901

Wire: Pluto tone → switch → SM200B. Syscomp square wave on the control pin.

You get: loss when on, leakage when off, and switching time.

TX-4. TX mixer

ZX05-14LH-S+

Wire: Pluto 1.0–1.2 GHz → IF port, LO 8.3 GHz → LO port, RF port → SM200B.

You get: power at 9.3 to 9.5 GHz, the unwanted image at 7.1 to 7.3 GHz, and LO leakage at 8.3 GHz. This also becomes the test source for the RX chain.

TX-5. Image filter

VHF-8400+

Wire: TX-4 output → filter → SM200B.

You get: loss at 9.3 to 9.5 GHz (expect 1.4 to 1.6 dB) and how far the image and LO are pushed down (expect 24 to 28 dB at 7.1 to 7.3 GHz).

TX-6. Power amp

not picked

Wire: filter → amp → 30 dB attenuator rated for the power → SM200B.

You get: gain and maximum output. Do not run it without the attenuator.

Oscillators, keying and control

CTL-1. PLL

ADF5355

Wire: PLL → SM200B.

You get: frequency error at 8.3 GHz, output power, spurs, and how long it takes to lock after a change. Any LO error passes straight through to the reply.

CTL-2. Round-trip frequency

Wire: the whole thing, cabled through attenuators. Source in at 9.3 to 9.5 GHz, SM200B on the output.

You get: reply frequency minus input frequency, across the band and across input levels. Pass is ±1.5 MHz for long pulses, ±3.5 MHz for short ones.

CTL-3. Reply delay

FPGA timing

Wire: scope on the comparator output and on the keying line.

You get: time from radar pulse to start of reply. Pass is 0.7 µs or less.

CTL-4. Morse and blocking

Wire: SM200B capturing the output, repeated input pulses.

You get: the keyed letter with dash equal to three dots, and no reply for 100 µs after the previous one ends.
