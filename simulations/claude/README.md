# JACON simulations (Claude)

Simulation package for `../../racon_draft_design01b_drawing.pdf`: receive a ~9.4 GHz radar pulse, measure its frequency, and reply at the same frequency with Morse `. - .`.

| folder | what | start here |
|---|---|---|
| [`01_jacon_system/`](01_jacon_system/README.md) | LTspice model of **every block** in the drawing, grouped in numbered boxes, with **one `.param TEST=n` switch** that picks what gets simulated (full system or any single function) | open `JACON_system.asc` in LTspice |
| [`02_delay_line_discriminator/`](02_delay_line_discriminator/README.md) | stand-alone 1.0–1.2 GHz model: tone → splitter → two cables (+4.5") → multiply → low-pass → `cos(2πfΔt)` | open `delay_line_discriminator.cir` |
| [`03_gnuradio_pluto/`](03_gnuradio_pluto/README.md) | GNU Radio Companion flowgraph and scripts to drive the real network from an ADALM-Pluto, log readings, and compare with the simulation | open `jacon_pluto_discriminator_tx.grc` |
| `common/` | shared Python helpers (LTspice batch runner, `.raw` reader, FFT) | – |

All plots are regenerated by the Python scripts in each folder. Use the radioconda interpreter, which has numpy, scipy, matplotlib and GNU Radio:

```bash
%USERPROFILE%\radioconda\python.exe 01_jacon_system\run_tests.py
```
```bash
%USERPROFILE%\radioconda\python.exe 02_delay_line_discriminator\plot_discriminator.py
```

## Headline findings

1. **The 4.5" delay does not centre the discriminator on 1.1 GHz.** At a typical PTFE velocity factor (0.70), Δt = 545 ps, which is 216° at 1.1 GHz, not 90°/270°. The curve stays monotonic over 1.0–1.2 GHz, but a straight-line (analog) inverse is off by up to **±17 MHz**. In the full RX→TX loop (TEST 10) the reply lands **+7 to +27 MHz** away from the radar frequency. With 5.63" or 1.88" the error drops to **< 6 MHz**. For quadrature at 1.1 GHz use **5.63"** (270°) or **1.88"** (90°). Either way, measure the real cable delay with the Pluto wide sweep, because connectors and VF tolerance move the answer a lot: at VF ≈ 0.84, 4.5" sits right on the zero-slope 180° point.
2. **The 8.3 GHz LO leaks out of the TX.** It sits inside the VHF-8400+ passband, so it comes out at about −17 dBc and stays on between Morse elements.
3. **The ADA4622 is slow for the tune path.** At the gain needed (≈19 V/V) it takes about 0.76 µs to settle the VCO to 1 MHz. Either allow that holdoff or use a faster op-amp.
4. The limiter lets about +16 dBm reach an LNA rated for +15 dBm, so keep the in-line pad. LO drive at the mixers has only about 0.3 dB of margin (with an assumed +3 dBm PLL output).

Details, figures and the remaining numbers are in each folder's README and `plots/`.
